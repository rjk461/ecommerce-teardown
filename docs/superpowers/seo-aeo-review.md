# SEO and AEO review, 30 September 2026

Scope: every indexed page on ecommerceteardown.com, checked against the built root `*.html` and `*.md` files, plus live checks of robots.txt, sitemap, llms.txt and headers. Five specialist reviews (technical, content, schema, sitemap, AI search) were run, and each finding below was checked against the page itself before it was acted on. A review is a claim; the evidence column says what was actually looked at.

Baseline: Cloudflare Agent Readiness score 33 (Level 2), scanned 2026-09-30 09:22 AEST. PageSpeed Insights mobile, homepage, 2026-09-30 12:12 pm: Performance 77, Accessibility 100, Best Practices 96, SEO 100.

## Passed, and what would have failed it

| Check | What was looked at | What would have failed it |
|-------|--------------------|---------------------------|
| AI crawlers allowed | `robots.txt` and a live request as GPTBot, ClaudeBot, PerplexityBot and Google-Extended | A `Disallow` for those agents, or a 403 |
| Server-rendered text | Built HTML of every page, over 1,000 characters each | A page whose body arrives by JavaScript |
| One H1 per page, unique titles and descriptions | `tests/structure.test.mjs` (title 20 to 70, description 70 to 170) | A duplicate or over-length value (this caught the home description twice during this PR) |
| Canonical, `og:url`, sitemap locs on the production host | Built pages and `sitemap.xml` | A `localhost` or `www` URL |
| `llms.txt` and `.md` mirrors | Present and well formed, regenerated by the build | A missing mirror or a stale description |
| JSON-LD parses | Every block parsed in tests | A syntax error |
| Horizontal overflow | 1280, 900, 769, 768 and 375 px, every page | Any page wider than the viewport |

## Page speed

Lab measure, local, mobile emulation (4x CPU slowdown, 1.6 Mbps, 150 ms latency, median of 5, Google and Reddit tags blocked so the numbers isolate the site itself):

| Page | Before (main) | After (branch) |
|------|---------------|----------------|
| Home, FCP and LCP | 1,976 ms | 2,152 ms |
| /consulting | 1,924 ms | 2,024 ms |
| /ai-strategy | 1,616 ms | 1,528 ms |

These differences are inside run-to-run noise, so this measure shows no gain and no loss from the site's own files. It cannot show the main cost PageSpeed Insights reported (the Reddit pixel pulling a second script from Reddit's servers while blocking the page), because those requests were blocked to keep the test repeatable. The target (LCP at or under 2.5 s, Performance 90 or more) is therefore not yet confirmed. The real check is PageSpeed Insights on production after merge.
